# Chrome Selected Site Bridge

本地开发版本，未上传 Chrome Web Store。不会安装到您现有的 Chrome，也不会读取浏览器数据库。

1. 运行本项目工作台 `http://127.0.0.1:8946`。
2. 在 Chrome 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。
3. 工作台中创建或选择目标平台和账号，生成一次性配对码。
4. 在 Chrome 普通窗口打开该平台主站，并自行确认已登录的身份。点击扩展图标；扩展会记住所选来源标签页，并打开持久导入页。在新页输入配对码。
5. 核对扩展显示的站点与保存账号，勾选身份确认，点击“授权此站点并导入一次”。Chrome 会单独请求该站点权限。
6. 本机保存成功后，扩展收回该站点权限。账号状态是 `saved_unverified`；需要实际平台采集判断是否登录有效。

配对码 120 秒有效且只能交换一次；授权凭证最多 10 分钟有效且只允许一次成功导入。凭证仅在扩展内存会话与服务内存中保存；服务重启、扩展重载或撤销后需重新配对。扩展没有后台脚本、内容脚本、自动同步或全站 Cookie 查询。

仅导入从工具栏入口选定的原普通窗口标签页所用 Cookie 容器、精确主站 HTTPS 根 URL 可见的非分区 Cookie。导入页本身不是来源；授权后与传输前都会重新检查原标签页的主站、普通窗口及 Cookie 容器。原标签页关闭、换站或换容器会拒绝导入。请保留来源页和导入页直到完成。不会读取其他 Chrome profiles、隐身窗口、本地存储或非根路径 Cookie；这些边界可能导致部分平台会话不完整。扩展无法判定 Cookie 对应的真实用户，身份对应关系必须由本人确认。一次导入会替换所选目标账号已有的本机保存状态。

配对撤销只阻止尚未使用的导入授权；删除已保存的账号会话请在工作台“撤销账号”操作。扩展移除也不会自动删除工作台已保存会话。

此版本固定使用 `127.0.0.1:8946`，不允许远程服务器或自定义上传 URL。CookieBridge 在非 Windows 系统安全拒绝启用，避免退回明文存储。
