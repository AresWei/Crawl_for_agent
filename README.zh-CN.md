![Crawl_for_agent 概念插画](docs/assets/hero.png)

*概念插画，不是软件界面截图。*

Crawl_for_agent 将网页采集、平台适配、搜索和有来源的回答整合为一个本地研究程序及智能体技能。它把 [Crawl4AI](https://github.com/unclecode/crawl4ai) 与 [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) 的部分能力接入共享任务调度、证据存储、浏览器与会话生命周期、资源预算。

这是独立的**源码预览版**，不是上游官方产品、直接兼容替代品，也不宣称全部功能等价。内部 Python 包及部分命令仍使用 `research_crawler` 名称。

## 一条可以回查的研究流程

1. **发现**：从搜索、站点地图或支持的平台入口找到候选来源。
2. **采集**：保存实际正文与记录，保留来源身份、版本及读取范围。
3. **回答**：使用已保存证据，选取引文，并单独检查结论是否受到支持。
4. **恢复与导出**：继续未完成任务，保留失败来源，不把部分覆盖写成全部成功。

![证据流程概念插画](docs/assets/evidence-flow.png)

*概念插画；实现细节与边界见[架构说明](docs/ARCHITECTURE.md)。*

请求失败或预算耗尽时，程序尽可能保留已获得的原文与已审核结论。因此，回答可以有用，而整个任务仍是 `partial`。引文和模型审核提高可追溯性，不保证每次理解都正确。

## 包含什么

| 方向 | 能力 |
|---|---|
| 网页 | HTTP 与浏览器采集、HTML/Markdown、结构化提取、有界站点探索、截图、缓存导入导出 |
| 搜索与回答 | 联网发现、本地文字检索、可选多语言语义检索、引用已保存原文的回答 |
| 平台 | 小红书、抖音、快手、B站、微博、贴吧、知乎适配器；各平台操作范围不同 |
| 会话 | 显式选择账号、正常浏览器登录、所选站点扩展导入、账号与代理固定配对 |
| 签名 | 小红书、抖音、知乎可选本地计算或独立本机服务；快手保留浏览器依赖 |
| 媒体与输出 | 媒体下载、可选本地 OCR/转写/视觉、评论分析、报告、文件与数据库导出 |

模型提取、分析及图片工作流需要另外准备对应运行时与模型，并非所有采集任务都需要它们。

## 平台能力与真实验证分开看

![平台研究概念插画](docs/assets/platform-research.png)

*概念插画，不是平台界面，也不是验收截图。*

近期最完整的授权平台样本来自**小红书**：搜索与详情、两页根评论、创作者列表、图片下载、使用独立签名服务的首页，以及真实扩展导入后的单篇详情读取。它们是有限样本，不证明全部子回复、所有媒体类型或未来登录有效性。

源码包含七个平台，**不等于七个平台所有流程均已实测通过**。账号/代理池已有本地集成验证，通过真实代理访问平台的联合池仍未验收。详细状态见[能力矩阵](docs/CAPABILITIES.md)。

## 回答方式与费用边界

独立程序新建回答任务默认通过 **Codex CLI 复用已有 ChatGPT/Codex 账号**，读取保存的来源上下文。它需要联网、使用账号可用额度，不要求 OpenAI API Key，不静默回退到付费 API；但它**不是无限免费或完全离线**。

在已有 Codex 对话中，技能可以组合宿主搜索工具与本程序保存的原文，由当前对话直接回答。宿主工具不等于独立程序内置搜索 API。已配置的本地文本模型仍是实验选项，其语义质量尚未达到相同验收标准。

## 运行源码预览版

已有配置的 **Windows 环境**经过实际运行。尚未完成从本公开快照开始的全新安装验收，也不能把 Windows 结果外推为 Linux/macOS 已支持。

快照不包含运行时、浏览器二进制、模型权重、本地状态、账号会话、令牌、私有配置与已采集研究数据。请先准备依赖及所需可选组件；克隆仓库并不等于获得完整可运行安装包。

完成环境准备后，可使用 PowerShell 入口：

```powershell
# 查看已配置能力；这些命令不会安装依赖。
.\scripts\research.ps1 status
.\scripts\research.ps1 doctor

# 启动本机工作台服务。
.\scripts\start-research.ps1
```

默认工作台地址为 `http://127.0.0.1:8946`，请保持本机使用。[使用说明](docs/USAGE.md)包含任务示例，并区分登录、导入与采集。

## 当前边界

公共搜索与平台入口可能拒绝、限流或超时；部分登录探针无法确定账号状态。新签名/池管理界面有实现及有限接口证据，尚无完整视觉交互验收。长截图通过了有限完整与上限工作台样本，历史独立诊断进程退出原因仍未确定。本地模型质量、任意图片编辑效果也不是普遍保证。

请在[能力矩阵](docs/CAPABILITIES.md)中分别查看“已实现”“本地验证”和“真实有限样本”的区别。
