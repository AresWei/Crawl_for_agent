# Crawl_for_agent

**从网页与平台内容，到有据可查的回答。**

[English](README.md) · [简体中文](README.zh-CN.md) · [环境准备](docs/GETTING_STARTED.md) · [架构](docs/ARCHITECTURE.md)

![Crawl_for_agent](docs/assets/hero.png)

Crawl_for_agent 是一个自主构建、面向智能体的研究程序。初版用**两天一夜**从零搭建项目工程与统一架构，贯通来源采集、会话管理、证据保存和研究回答。

网页、平台内容、搜索与分析共用一套任务系统。可以通过智能体、本机工作台或命令行使用；采集的资料会留下来，继续服务下一个问题。

## 核心能力

| 能力 | 可以做什么 |
|---|---|
| 网页采集 | 通过 HTTP 或浏览器保存 HTML、Markdown，提取结构化字段，在预算内探索网站并保存截图 |
| 平台研究 | 接入小红书、抖音、快手、B站、微博、贴吧、知乎适配器，按各平台支持范围采集搜索、详情、创作者内容和评论 |
| 搜索与回答 | 联网发现来源，检索已采集资料，可选跨语言语义检索，使用关联原文的引用回答 |
| 会话与签名 | 选择已保存账号，正常登录或导入所选站点会话，将账号与已有代理配对，按支持范围选择本地或独立服务签名 |
| 媒体与分析 | 下载媒体，按需使用 OCR、转写、视觉理解，并分析已采集评论 |
| 研究输出 | 保存版本化记录、恢复任务、生成报告，导出到文件或已配置数据库 |

![平台研究](docs/assets/platform-research.png)

## 一条连贯的研究流程

**发现 → 采集 → 阅读 → 回答 → 复用**

搜索找到候选来源，采集保存真实材料及来源信息。回答从记录中选择原文引用，再逐条检查结论是否获得支持。留下的研究资料库可以继续检索、导出或用于后续任务。

![证据流程](docs/assets/evidence-flow.png)

任务共用预算、断点和资源管理。来源暂时不可用或任务达到上限时，程序保留已取得的材料与已审核结论，并说明实际覆盖范围。

## 面向 Agent Harness

**Codex、Claude Code 等智能体宿主**可以通过 [Skill](skill/research-crawler/SKILL.md)、CLI 或本地 API 调用 Crawl_for_agent。智能体负责组织研究，程序负责采集、保存和返回证据。

![Agent 宿主集成](docs/assets/agent-harness.png)

推理由宿主按其支持的方式使用**模型 API 或订阅额度**，模型访问、计费与可用工具遵循宿主配置。例如，宿主智能体通过 CLI 采集网页后，可以直接在当前对话中依据原文回答。

宿主配置、调用接口与独立程序的回答后端设置见 [Agent 接入指南](docs/AGENT_INTEGRATION.md)。

## 用自然语言提出任务

> 找到这项行为的官方文档，保存相关网页，再用原文引用解释它。

> 采集选定创作者近期的帖子和评论，总结反复出现的问题，并把每项发现关联到原始内容。

> 只使用我已经采集的资料，比较不同解释，指出哪些地方证据还不充分。

任务参数与示例见[使用说明](docs/USAGE.md)。

## 环境准备

按照[环境准备指南](docs/GETTING_STARTED.md)配置 Windows、Python 依赖、Node.js，以及任务需要的浏览器组件。模型辅助任务配置所选智能体宿主或独立回答后端；本地模型按需要启用的可选功能准备。

在已配置的项目目录运行：

```powershell
.\scripts\research.ps1 status
.\scripts\start-research.ps1
```

在 `http://127.0.0.1:8946` 打开工作台。
